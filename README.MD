# 프로그램 개요

1. 사용자로부터 하나 이상의 영단어를 입력받는다.
1. 영한 해설, 영영 해설 중 선택한다.
    1. 영한 해설일 경우 [네이버영어사전](https://en.dict.naver.com/#/main)
    1. 영영 해설일 경우 [캠브리지영어사전](https://dictionary.cambridge.org/ko/)
1. 크롤링 도구는 selenium
1. 입력받은 영단어들을 각 사전에 검색하고 결과를 크롤링
1. 크롤링한 raw 데이터를 html 태그를 이용해 데이터 종류를 구분한다.
    1. 단어, 사진, 발음 파일, 발음 기호, 품사, 뜻, 예문 등
1. 전처리한 데이터를 기준으로 txt 파일을 생성한되, 파일제목은 날짜를 기준으로 한다. ex) 20211222_영단어.txt  
    1. 같은 이름의 파일이 있을 경우 기존 파일을 연다.
    2. format 형태는 csv 파일과 동일하게 하고, 순서는 차례대로 영단어, 발음, 뜻, 태그로 한다.

selenium 같은 크롤러를 코딩할 때는 봇으로 동작하는 크롬이랑 내가 만지는 크롬이랑 페이지 화면이 다를 수 있으니까 꼭 확인하면서 코딩하기!!!
